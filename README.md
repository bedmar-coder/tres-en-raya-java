# Tic-Tac-Toe in Java

A console tic-tac-toe game for two players that I made while learning Java. You pick the board size, take turns typing cells like `A-1`, and the game tells you who won (or if it's a draw).

**Just so it's clear:** this isn't a finished game or anything meant for real use. It's a practice project I wrote to learn the language: classes, enums, 2D arrays and reading input from the console. It still has some rough edges.

## Running it

It's a NetBeans project, so the easiest way is to open the `PRG-SA6-TresEnRaya-main` folder in NetBeans. The game itself starts from the `TicTacToe` class.
